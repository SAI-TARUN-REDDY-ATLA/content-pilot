# Background footage

Drop vertical or landscape clips here (`.mp4`, `.mov`, `.mkv`, `.webm`): gameplay
(Minecraft parkour, Subway Surfers style runs), satisfying loops, slime, kinetic sand.
Each video picks one at random and starts at a random point. Clips are cropped to
fill 1080x1920, and short ones loop.

When the folder is empty, a colour-cycling placeholder is generated as
`_placeholder.mp4`. Files here are git-ignored; only use footage you have the rights to.
